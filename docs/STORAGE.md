# Storage — v1.0.0

No database. All storage is filesystem, mostly parquet + torch checkpoints.

| Path                                                 | Format                    | Committed?                       | Contents                                                                                                                                                                                |
| ---------------------------------------------------- | ------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `artifacts/Text_dataset.br`                          | brotli-compressed parquet | Yes                              | Raw consolidated Reddit/Twitter text, source for `build_datasets.py`.                                                                                                                   |
| `src/data/{version}/{train,valid,test}_data.parquet` | brotli parquet            | **No** (gitignored, not present) | Generated by `build_datasets.py`; required input for `build_model.py`.                                                                                                                  |
| `src/model/{version}/model.pth`                      | torch checkpoint (`.pth`) | **No** (gitignored)              | Model weights, epoch, optimizer state, loss. Required for the API/CLI/GUI to serve real predictions.                                                                                    |
| `src/model/{version}/report.txt`                     | text                      | Yes                              | `sklearn.classification_report` output.                                                                                                                                                 |
| `src/model/{version}/training_history.csv`           | csv                       | Yes                              | Per-epoch train/val loss + accuracy.                                                                                                                                                    |
| `src/model/{version}/*.png`                          | image                     | Yes                              | Confusion matrix + loss/accuracy curves.                                                                                                                                                |
| `src/Text-Preprocessing-Data/*.csv`                  | csv                       | Yes                              | Abbreviation, apostrophe, emoticon lookup tables — resolved relative to the package/module directory via `os.path.dirname(os.path.abspath(__file__))` (DECISIONS.md #10, fixed v1.0.1). |

## Implication

Reports and metadata are committed; the actual model weights and intermediate datasets are not. This makes the repo good for showing *evidence* of past training runs but means it cannot serve a real prediction, or resume training, without external artifacts nobody currently publishes (no release, no model registry, no download step in `Dockerfile`).
